Why this exists

Preeti still runs Nepal's paperwork

Preeti isn't real Devanagari Unicode — it's a font that maps ordinary keyboard letters onto Nepali-looking glyphs. Type g]kfn with Preeti applied and you see नेपाल — remove the font, and it's meaningless ASCII again. That trick still powers a lot of government forms, court paperwork, and older DTP templates (PageMaker, CorelDRAW, old Word macros) built years before Unicode became standard. This tool bridges the two: write normally in modern Unicode, get legacy-correct Preeti keystrokes back out.

Notes & instructions

Good to know

The output looks like scrambled English, not Nepali

That's expected until the Preeti font finishes loading in your browser — it's loaded automatically from a public CDN the first time you open this page. If it never loads (e.g. you're fully offline), you'll see a warning banner above with a link to download and install Preeti locally. Either way, the underlying text is already correct — only the visual font is missing.

Why does it reorder some letters?

Preeti is a visual-order font, while Unicode stores letters in logical (spoken) order. Two Nepali marks always move: the short ि matra jumps to before its consonant (Unicode: कि → Preeti keys: ल + क), and reph (र् at the start of a syllable) jumps to after the whole cluster it sits over. This converter handles both automatically.

Can I type Romanized Nepali directly?

Yes — select Roman → Unicode above the panels. Type phonetically (e.g. ramro, dhanyabad), and see live Nepali Unicode on the right. This is a best-effort phonetic guess with no dictionary behind it, so double-check longer words.

Can it go the other way — Preeti to Unicode?

Yes. Select Preeti → Unicode above the panels, or hit the ⇄ button to cycle to it. Paste old Preeti-font text (the kind that looks like scrambled English until you apply the Preeti font) into the left panel, and get clean, modern Unicode Nepali on the right — usable anywhere, no special font required.

Is my text uploaded anywhere?

No. Every conversion runs locally in your browser with plain JavaScript — nothing is sent to a server, logged, or stored. You can even save this page and use it fully offline once the font is cached.

Does this work for documents, not just short text?

Yes — paste as much text as you like into the left panel. For a full document already in a Word or PDF file, you'd still need to extract the text first; this tool converts plain text only.

Known limits. This engine covers the full common alphabet, matras, digits, punctuation, reph, and the standard conjuncts (क्ष, त्र, ज्ञ, श्र, द्य, द्व, ङ्ग and friends). A handful of very rare letters and multi-consonant stacks (ॠ, ऌ, uncommon four-letter conjuncts) fall back to a generic — usually still readable — combination rather than a dedicated shortcut key. For anything going to print or an official document, give the Preeti output a quick visual check before sending it off.
